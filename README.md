# Demand Planning

## Запуск

Из корневой директории проекта выполните:
1. Установка зависимостей

```bash
pip install -r requirements.txt
```
2. Запуск пайплайна

```bash
python src/main.py
```

Точка входа: `src/main.py`.

*Пайплайн последовательно выполняет подготовку данных, выбор метода прогнозирования и построение прогноза. Для запуска необходимы Python 3.10+ и библиотеки `pandas`, `numpy`.*
